# Данные MASSIVE

Источник: [Amazon Science MASSIVE](https://huggingface.co/datasets/AmazonScience/massive),
[репозиторий авторов](https://github.com/alexa/massive).
Авторы: Jack FitzGerald и соавторы, Amazon Science, 2022.
[Публикация](https://arxiv.org/abs/2204.08582).
Датасет распространяется по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

В репозиторий включена зафиксированная русская выборка `massive_ru.csv`:
16 521 фраза, 60 намерений. Это локальный снимок, а не обещание совпадения с
текущей версией на Hugging Face. CSV используется без загрузки из сети при запуске.

SHA-256 файла: `c8cfa1f16a676bf9e47891801904efc5498eefbdf2004f9853c3b33e40055fa1`.

| Колонка | Содержимое |
| --- | --- |
| id | исходный идентификатор фразы |
| partition | train / dev / test |
| scenario | сценарий, например alarm |
| intent | намерение, например alarm_set |
| utt | текст фразы на русском |
| annot_utt | тот же текст с разметкой `[time : семь утра]` |

Исходное распределение: train — 11 514, dev — 2 033, test — 2 974.
Выгрузка сохраняет тексты и разметку, представляет поля в CSV.
ETL нормализует пробелы, проверяет данные и удаляет повторы: после очистки остаётся
15 642 фразы. Разделы не перемешиваются; при повторе сохраняется первое вхождение
в файле. Русские названия и правила обязательности параметров добавлены в
`app/etl/labels.py` и являются частью приложения, а не исходной разметкой MASSIVE.

Качество классификации измеряется только по намерениям. Метрики извлечения
параметров отдельно не заявляются. Синтетические пользователи и команды создаются
скриптом `app.seed`; это демонстрационные данные, а не история реального сервиса.
