## Браузерный сценарий

Проверка Playwright в Chrome, реальные запросы к запущенному FastAPI/PostgreSQL.
События ASR и завершения TTS имитируются: тест не обращается к настоящему микрофону.

- При загрузке микрофон не запускается.
- «Поставь будильник» → вопрос о времени → «на семь утра» → проговаривание и да/нет.
- «Да» → ready, execution_confirmed=false; ложного сообщения об установленном
  будильнике нет.
- После перезагрузки сохранённый диалог восстанавливается без включения микрофона.
- Тестовая квитанция через API → опрос клиента получает executed и показывает
  текст, явно отмеченный как тестовый. Реальный будильник не создаётся.
- Escape останавливает микрофон; Alt+M возобновляет диалог.
- ASR не слушает во время TTS.
- Отказ доступа к микрофону и сетевая ошибка дают сообщение и текстовый резерв.
- Неверное время 99:99 даёт 400; корректный ответ продолжает тот же диалог.
- Неоднозначное согласие отклоняется; «нет» отменяет команду.
- Отмена до передачи доступна отдельной кнопкой.
- Три события отсутствия речи останавливают микрофон с объяснением; команда сохранена.
- Тайм-аут 60 проверок не превращает ready в успех. Повтор запрашивает текущее состояние.
- Новый диалог предупреждает о неподтверждённой предыдущей команде и не меняет её статус.
- При отсутствии SpeechRecognition голосовая кнопка отключена и открыт текстовый ввод.
- При отсутствии синтеза речи отключены собственное озвучивание и повтор; текстовый резерв доступен.
- Регулятор скорости: управление клавишами, передача rate в TTS (0,5–2×),
  сохранение после перезагрузки, резерв при недоступном localStorage, отклонение
  повреждённых значений настройки и отключение ползунка без TTS. Проверено в Chrome
  с имитацией синтеза; на ширине 390 px горизонтального переполнения нет.
- Экран 390 px не имеет горизонтального переполнения.
- Ошибок JavaScript в проверенном сценарии нет.

## Границы доказательств

Автотесты не заменяют проверку настоящей речи, качества русских голосов ОС,
работы конкретного экранного диктора и испытания с незрячими участниками.
Метрики MASSIVE относятся к классификации текста, не к ASR и не к доступности.
Нет интеграции с реальным устройством. Сертификация WCAG не заявляется.

Ранее отдельно проверялись ETL/seed bootstrap на пустой PostgreSQL БД и повторный
импорт без дубликатов. Факт локальных проверок не подтверждает запуск GitHub Actions,
защиту main или peer review; для этого нужны реальные ссылки удалённого репозитория.
pytest сообщает предупреждение Starlette о будущем переходе TestClient с httpx
на httpx2; тесты проходят.

## Браузерные исполнители, 7 ноября 2026

После добавления исполнителей: 132 pytest-теста, покрытие 91,82%; 16 frontend-тестов.
Ruff check/format, Prettier и production-сборка проходят. Docker Compose собран
повторно; приложение на localhost:8010 и PostgreSQL имеют статус healthy.

В Chrome и Firefox проверены будильник через минуту, выключение/включение света
и запрос даты/времени. До «да» действие не происходит; затем браузер отправляет
POST /execution. Для всех четырёх операций GET /api/dialogues/{id} подтверждает
phase=executed, execution_confirmed=true и совпадение execution_message с UI.
Новая команда сохраняет отсчёт; проверены срабатывание и удаление будильника
кнопкой остановки. Ошибок JavaScript и переполнения на ширине 390 px нет.

В Chrome результаты ASR и TTS имитировались. В Firefox использовались настоящие
AudioWorklet, WAV и Vosk: синтезированные записи «Поставь будильник», «Через минуту»,
«Да», затем ещё три голосовых подтверждения. Шесть записей, ноль перекрытий
микрофона с TTS, одно начальное приглашение. TTS имитировался, физический микрофон
не использовался. Срок сигнала ускорен через Playwright Clock; проверено создание
реальных Web Audio-осцилляторов, но слышимость через физические колонки не измерялась.

Node-тесты дополнительно проверяют отсутствие ложного успеха без звука и при
ошибке HTTP, повтор квитанции без повторного эффекта и восстановление сохранённого
срока. Права/громкость конкретного браузера и надёжность таймера во сне компьютера
остаются ограничениями, описанными в [браузерных исполнителях](browser-execution.md).
